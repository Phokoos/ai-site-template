# 1. Context

## Purpose

Produce the **Context** artifact for one feature using the repository's own language, framework, commands, and conventions.

## Before starting

Read the repository. If it is missing or insufficient, stop with `BLOCKED` rather than guessing.

## Procedure

1. Read relevant repository files and prior artifacts.
2. Apply the questions below.
3. Record decisions and evidence in the stage artifact.
4. Check the gate before handing off.

## Questions and checks

- What does the repository contain?
- Which runtime, frameworks, dependencies, entry points, and conventions matter?
- Which similar implementation should be reused?
- What constraints and commands are known?

## Gate

The artifact is ready only when it is complete, evidence is honest, and no blocking question remains. For Review, the status must be `PASS`; otherwise use `READY` or `BLOCKED`.

## Handoff

Use the standard handoff format from `AGENTS.md`, including the exact artifact path and next stage.
